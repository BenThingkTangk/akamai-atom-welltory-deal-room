# Copy rules

Never claim:
- Akamai makes Welltory HIPAA compliant
- Proposed HIPAA changes are already a final 2026 mandate
- Zero downtime
- Zero engineering work
- Guaranteed savings
- Guaranteed migration duration
- Guaranteed pricing
- Guaranteed buyout
- C-level approval without explicit recorded approval
- Akamai does not lose on price
- Cloudflare cannot protect Welltory

Use:
- Proposed HIPAA Security Rule modernization
- Healthcare-security readiness
- Operational evidence
- Intended to minimize
- Subject to discovery
- Subject to approved scope
- Where approved
- Acceptance criteria
- Competitive evaluation

Never seed or display in customer output:
- `$35K`
- `$423K`
- "customer confirmed"
- "Welltory: Yes"
- Claims about how internal information was obtained

The `guardCustomerPayload` helper enforces this at publish time.
